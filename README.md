# Turnamen Catur KSL

Preview tampilan aplikasi manajemen turnamen catur dari **King Sang Long (KSL)**.

**Lihat preview:** https://fnzahra.github.io/ksl-chess/

Fitur yang ditampilkan:
- Daftar dan pencarian turnamen
- Pendaftaran peserta
- Pairing, klasemen, dan tabel silang
- Panel penyelenggara dan klub

Aturan pertandingan mengikuti standar FIDE dan PERCASI.

> Ini versi demo. Data yang tampil adalah contoh dan hanya tersimpan di browser kamu.
